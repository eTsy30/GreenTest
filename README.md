# Тестовое задание на должность «Фронтенд разработчик React»

Интерфейс для отправки и получения текстовых сообщений в **WhatsApp** через
сервис [GREEN-API](https://green-api.com/). Используется допустимый в задании вариант WhatsApp.
Интерфейс минимальный: боковая панель, шапка чата и текстовые сообщения.
Точное визуальное соответствие [web.max.ru](https://web.max.ru/) не подтверждено.

## Возможности

- Подключение по учётным данным GREEN-API (`idInstance`, `apiTokenInstance`) с проверкой
  состояния инстанса (`GetStateInstance`).
- Создание чата по номеру телефона получателя методом
  [`CheckWhatsapp`](https://green-api.com/en/docs/api/service/CheckWhatsapp): метод возвращает
  `chatId` получателя, по которому GREEN-API ведёт переписку.
- Отправка текстовых сообщений методом
  [`SendMessage`](https://green-api.com/docs/api/sending/SendMessage/).
- Получение сообщений методом
  [`ReceiveNotification`](https://green-api.com/docs/api/receiving/technology-http-api/ReceiveNotification/)
  (long polling) с удалением обработанных уведомлений через `DeleteNotification`.
- Отображение статусов отправленных сообщений из уведомлений `outgoingMessageStatus`
  (`delivered`, `read`, `failed`).

Поддерживается только текст. Функционал намеренно минимальный: один активный чат,
одно поле ввода и отправка по `Enter`.

## Локальный запуск

Требуется Node.js 20.19+ (ветка 20) или 22.12+. Рекомендуется Node.js 22 LTS.

```bash
npm ci
npm run dev
```

Приложение откроется на `http://localhost:5173` (Vite подберёт свободный порт, если
основной занят).

Сборка продакшен-версии и локальный просмотр сборки:

```bash
npm run build
npm run preview
```

Проверка кода:

```bash
npm run lint
npm test
```

## Настройка

Адрес API берётся из переменной окружения `VITE_API_HOST` (по умолчанию
`https://api.green-api.com`). Создайте файл `.env` рядом с `package.json`:

```
VITE_API_HOST=https://api.green-api.com
```

Файл `.env` не коммитится. Учётные данные инстанса вводятся пользователем в интерфейсе
и сохраняются в `localStorage` браузера.

## Сценарий проверки

1. Откройте приложение и введите `idInstance` и `apiTokenInstance` инстанса,
   авторизованного в личном кабинете GREEN-API.
2. Укажите номер телефона получателя в международном формате (например,
   `375333900033`) и нажмите «Создать чат».
3. Отправьте текстовое сообщение — получатель увидит его в WhatsApp.
4. Ответьте в WhatsApp — сообщение появится в чате веб-интерфейса без перезагрузки
   страницы.

## Получение сообщений и диагностика

При открытии чата приложение проверяет `GetSettings`, включая вход после
перезагрузки страницы. Если нужно, `SetSettings` включает `incomingWebhook` и
`outgoingWebhook` и очищает `webhookUrl` для получения через HTTP API.
Используйте отдельный инстанс для этого приложения: настройка отключает доставку
на ранее заданный webhook URL. Применение настроек на стороне GREEN-API может
занять некоторое время — после этого отправьте новое сообщение с телефона.

Поддерживаются `textMessage` и `extendedTextMessage` (в том числе текст со ссылкой).
При сопоставлении получателя учитываются `@lid` и `@c.us`. После обработки события
вызывается `DeleteNotification`; неподдерживаемые события тоже удаляются, чтобы
не блокировать очередь. Ошибки видны в чате, опрос автоматически повторяется.
Индикатор подключения показывает состояние опроса API, а не онлайн-статус контакта.

Если ответ не появился:

1. Проверьте, что инстанс WhatsApp авторизован и настройки уведомлений применились.
2. Закройте другие вкладки этого чата и другие клиенты `ReceiveNotification`:
   они используют одну очередь и могут забирать уведомления.
3. Отправьте новое обычное текстовое сообщение от выбранного получателя.
4. В DevTools → Network проверьте ответ `receiveNotification`: `null` означает,
   что очередь пока пуста. Ошибка запроса отображается в интерфейсе.
   Не публикуйте URL запросов: в них содержится токен.

История хранится только в памяти и очищается при новом чате или перезагрузке.
Приложение отображает только выбранный чат; уведомления остальных чатов удаляются
без отображения. Для демонстрации используйте тестовый инстанс.

Автотесты проверяют разбор текстов, сопоставление ID, последовательность
получения/удаления уведомлений, восстановление после ошибки и отмену опроса.
Реальную доставку необходимо проверить двумя аккаунтами по сценарию выше.

- Инструкция запуска: этот README (после публикации изменений в репозитории).
- React, вход по idInstance/apiTokenInstance, создание чата по телефону,
  SendMessage и ReceiveNotification/DeleteNotification реализованы для WhatsApp.
- MAX API не реализован; WhatsApp разрешён условиями задания.

  с Telegram и при желании опубликовать демо и скриншоты.
